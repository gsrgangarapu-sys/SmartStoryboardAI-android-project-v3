# Smart Storyboard AI v3
Build: upload all files (including .github) to a GitHub repo, Actions > Build APK > Run workflow, download the APK, install.
First run on phone: Settings tab > Notification access (turn on Smart Storyboard AI), Allow SMS & alerts, Exact alarms.
Sideloaded Android 13+ may grey out notification access: App info > three dots > Allow restricted settings.
